# FF3 Pixel Remaster — Onion Equipment Cheat Table

Cheat Engine table for **FINAL FANTASY III Pixel Remaster**, Steam build **20264899**. Tested on macOS using CrossOver and Cheat Engine.

## 功能

- **四人轉洋蔥劍士並穿戴全套**：目前隊伍四人轉成洋蔥劍士，每人穿戴洋蔥劍、盾、頭盔、鎧甲、臂甲。
- **只補足四人份洋蔥裝備**：各種裝備總持有數補足至 4，不切換職業。

## 使用方式

1. 備份存檔，載入遊戲並停在地圖上。
2. 在 Cheat Engine 選擇實際執行中的 `FINAL FANTASY III.exe`。
3. 開啟 [FF3_PR_Onion_20264899.CT](FF3_PR_Onion_20264899.CT)。
4. 勾選需要的選項一次。
5. 回遊戲重新開啟裝備選單，另存至新的存檔欄位。

取消勾選不會撤銷已套用的改動。再次執行請先取消再勾選。CT 已內嵌全部腳本，不需要額外 Lua 檔。版本檢查不符時會拒絕執行。

## 黑／白魔法勾選介面（獨立 CT）

- [白魔法產生器](FF3_PR_WhiteMagicPicker_20264899.CT)：24 種白魔法，Lv1～8，物品 content ID 278～301。
- [黑魔法產生器](FF3_PR_BlackMagicPicker_20264899.CT)：24 種黑魔法，Lv1～8，物品 content ID 302～325。

載入存檔並停在地圖，CE 連接 `FINAL FANTASY III.exe`，開啟 CT 並勾選唯一項目即可顯示介面。個別勾選或全選魔法，設定每種目標數量（1～99，預設 4），按「補足勾選魔法」。只加入背包，不自動學習、不更換職業；持有量超過目標時保留原數，重複按不累加。完成後重新開啟遊戲道具／魔法選單，另存新欄位。

關閉介面只隱藏視窗；取消 CT 勾選會釋放介面，再勾選可重新開啟。取消勾選不撤銷已加入物品。發生錯誤時，先前成功加入的項目會保留，日誌會顯示錯誤；排除原因後可重試。
